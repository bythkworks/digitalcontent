# FLOWAY 제품 페이지

기존 축제 사이트의 `dist/PRODUCT03/`에 이 폴더의 `index.html` 및 `assets/`를 복사합니다. 축제 지도는 기존 `PRODUCT03/index.html` 링크를 그대로 사용합니다. 모든 이미지, 스크립트 및 GLB는 이 폴더의 상대 경로를 사용합니다.

## 실행

팀 사이트와 함께 확인하려면 기존 팀 사이트의 `dist/`에서 `python -m http.server 8000`을 실행한 뒤 브라우저에서 `http://localhost:8000/PRODUCT03/`를 엽니다. 개인 페이지만 확인하려면 ZIP을 푼 상위 폴더에서 같은 명령을 실행합니다. 팀 사이트 링크는 전체 사이트 안에서 동작합니다.

제품 디자인에서 ‘3D로 보기’를 선택하면 WebGL이 지원되는 브라우저에서 제품을 드래그하거나 터치해 회전할 수 있습니다. 로딩 중이거나 WebGL을 사용할 수 없으면 같은 섹션의 스튜디오 이미지 다섯 뷰를 이용할 수 있습니다.

## 이번 수정 (기능 누락 보완)

- 핵심 기능: 기능을 네 가지로 정리했습니다. AI가 먼저 시작하는 혼잡 대응(간격 조율)과, 착용자가 다이얼로 시작하는 이탈 요청을 구분합니다. 경로 재조정 기능과 두 신호(중앙 지시선·상부 LED와 진동)의 역할도 넣었습니다.
- 작동 방식: '혼잡 대응'과 '이탈 요청' 두 흐름으로 나눠, AI가 언제 판단하고 개입하는지 보여 줍니다. 이탈 요청은 경로 판단 → 기존 경로 막힘 → 경로 재조정 순서입니다.
- 다이얼 시연: '요청한 사람'과 '협조 알림을 받은 사람' 관점을 전환할 수 있습니다. 상부 LED는 색상과 점멸 방식이 확정되지 않아 켜짐 여부만 표시합니다.
- 사용 시나리오: 발표 자료의 14컷 중 9개 장면을 썼습니다(01, 05, 06, 07, 08–09, 10, 11, 12, 14). 각 장면에 반응하는 관람객을 표시했습니다.
- 새 이미지: 컷 05·07·10·12·14(`scene-*.webp`)는 발표 자료에서 잘라냈습니다. `dial-turn`, `crowd-alert-wrist`, `route-front-request`, `route-right-reroute`는 제공받은 이미지입니다. 번호가 찍혀 있던 `dial-action.webp`는 `dial-turn.webp`로 바꿨습니다.

## v3 수정 (2026-11-25)

- 히어로: 렌더에 박혀 있던 파란 점을 지우고, 빛나는 파란 점이 테두리를 따라 회전하도록 SVG 오버레이를 얹었습니다. 움직임 줄이기 설정에서는 멈춥니다.
- 문제 상황: 사진 카드 두 장을 탑뷰 축제 도면 스크롤 장면(5단계)으로 바꿨습니다. 인파는 '뭉친 무리' 스타일이고, 사진은 02·03단계에 작은 썸네일로 남겼습니다.
- 핵심 기능: 카드 5장을 한 장씩 넘기는 덱으로 바꿨습니다. 카드 위에서 휠을 굴리면 한 장씩 넘어가고, 카드 밖이나 첫·마지막 카드에서는 페이지가 그대로 스크롤됩니다. 터치에서는 옆으로 밀어 넘깁니다.
  - 다이얼 세 구역(이탈 희망 · 대기·AI 알림 · 이탈 불가), 파란 점 방향 안내, 위험 시 안전 거리 알림, 경로 재조정, 지시선 LED·진동
- 작동 방식: 관람 의사에 따른 구역 지도(관람 몰입/이탈 희망), 기존 두 흐름, 신호 4단계(LED·진동·지속 조건)를 넣었습니다.
- 다이얼 시연: 대기 때 나오던 양쪽 링을 없앴습니다. 진동은 기기 흔들림과 파형으로 보여 주고, 지시선이 LED 색·점멸을, 파란 점이 방향을 보여 줍니다.
- 사용 시나리오: 선택 버튼을 없애고 스크롤하면 장면이 넘어가는 구조로 바꿨습니다. 모바일에서는 장면이 위에서 아래로 쌓입니다.
- "상부 LED" 표현을 모두 정리했습니다. 파란 점 = 방향 안내, LED = 다이얼 지시선입니다.
- 도면 SVG는 생성 스크립트로 만들어 index.html의 `<!--TOPVIEW-->`, `<!--ZONEMAP-->` 사이에 들어 있습니다.

### 확정이 필요한 가정
- 지시선 색과 상태 연결: 이탈 희망 = 초록, 대기 = 주황, 이탈 불가 = 빨강, 협조 알림 = 노랑
- 이탈 불가는 위험 상황에서 시스템이 지시선을 X로 보내는 것으로 표현
- 컷 13(X 쪽으로 돌린 다이얼)은 의미가 확정되지 않아 쓰지 않음
