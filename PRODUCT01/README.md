# Knoble | 노블 — Product 01 페이지

College Festival 2031 · 제품 01 소개 페이지

## 여는 법
`index.html`을 더블클릭해서 브라우저(Chrome / Edge / Safari 최신 버전)로 열면 돼요.
인터넷 연결 없이도 동작해요. 3D 라이브러리, 3D 모델, 폰트, 영상이 모두 폴더 안에 들어 있어요.

## 폴더 구성
- index.html — 페이지
- style.css — 스타일
- js/app.bundle.js — 페이지 동작 + 3D 뷰어 (three.js 0.170 포함)
- js/more.bundle.js — 인물 · 시스템 장면
- js/knoble-model.js — 노블 3D 모델 데이터
- fonts/ — Noto Sans KR, Inter (SIL Open Font License)
- img/, media/ — 이미지와 에피소드 영상

## 참고
- 상단 "← FESTIVAL MAP" 링크는 온라인 메인 사이트로 연결돼요(인터넷 필요).
- 폴더 안 파일의 위치나 이름을 바꾸면 동작하지 않을 수 있어요.
